# MM Global Health Consulting

**Contributing to a world free from vaccine-preventable and neglected tropical diseases**  


</div>

---


[MMGH Consulting](https://www.mmglobalhealth.org/) is an independent, science-driven global health advisory firm based in Switzerland.

We support public and non-profit partners in developing, implementing, and evaluating evidence-based policies, strategies, products, and tools, with a focus on improving equitable access to essential health interventions.

This GitHub organisation hosts selected code, analytical tools, and resources developed or shared by MMGH Consulting.
